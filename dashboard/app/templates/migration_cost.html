Where the cost actually is

Both endpoints run on the same host with the same TLS version, certificate and cipher policy, differing only in the offered key-exchange group. Execution order alternates to remove sequencing bias and session resumption is disabled, so every sample performs a complete key exchange.

Latency is the number usually quoted, and it is small — under half a millisecond. The bandwidth figure is the one that matters: the ML-KEM encapsulation key and ciphertext push bytes sent from 484 to 1,651, past the point where a handshake fits in a single initial congestion window. On constrained or lossy paths that is where the real cost would appear.

Measured over loopback on a single t3.micro instance, so these figures isolate cryptographic and protocol cost with no network path. They are a floor, not a prediction of production latency.
